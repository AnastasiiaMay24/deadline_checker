# Deadline Checker

***Программа «Deadline Checker» предназначена для автоматизации  
проверки сроков сдачи контрольных работ. Она позволяет вычислять  
оценку с учетом опоздания и формировать список студентов, которые  
сдали работу позже установленного дедлайна.***

---
### Функции
- deadline_score — вычисляет оценку с учетом опоздания.  
- late_list — возвращает список должников в алфавитном порядке.
--- 

## Руководство пользователя

### Запуск программы
1. Скачайте проект с GitHub (кнопка *Code → Download ZIP*), распакуйте 
    архив в удобную папку.
2. Откройте терминал в папке с проектом.
3. Введите команду: 
```bash
python main.py
```
4. Нажмите Enter.
---
### Инструкция по работе
1. Ввод дат  
При запуске программа попросит ввести дату сдачи работы и дату  
дедлайна в формате ДД.ММ.ГГГГ (например, 10.10.2026).  
Если формат неверный, программа попросит ввести данные заново.  
2. Главное меню  
После ввода дат появится меню с вариантами действий.  
Введите цифру и нажмите Enter:  
1 — вычислить оценку за сдачу (с учетом опоздания).  
2 — сформировать список должников (студентов, сдавших позже дедлайна).  
3 — ввести даты заново.  
0 — завершить программу.  
3. Ввод данных о студентах  
Если вы выбрали пункт 2, программа попросит вводить фамилии и даты  
сдачи в формате Фамилия ДД.ММ.ГГГГ (например, Иванов 15.10.2026).  
Вводите по одному студенту на строку. Чтобы закончить ввод и увидеть  
результат, введите 0 и нажмите Enter.  
Если формат введен неверно (нет пробела, неверная дата), программа  
сообщит об ошибке и попросит повторить ввод.  
4. Результат  
Программа выведет список фамилий должников в алфавитном порядке.  
Если должников нет, будет выведено сообщение «Список пуст».
---
Возможные ошибки

«Ошибка! Формат дат: (ДД.ММ.ГГГГ)» — дата введена неверно 
(например, 3.10.2026 вместо 03.10.2026).
«Ошибка! Введите фамилию и дату через пробел!» — в строке ввода 
студентов нет пробела или введено лишнее слово.
«Ошибка! Попробуйте снова!» — в меню введена буква вместо цифры.
